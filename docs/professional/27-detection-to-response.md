# Detection to Response

Uma detecção madura conecta sinal a ação.

## Cadeia
telemetria → regra → alerta → triagem → evidência → decisão → contenção → remediação → melhoria.

Cada alerta deveria indicar:
- o que disparou;
- por que importa;
- quais entidades revisar;
- quais consultas usar;
- condição de escalonamento;
- resposta recomendada.

Essa conexão reduz tempo de análise e inconsistência operacional.
