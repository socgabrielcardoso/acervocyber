# Privileged Access

Privilégio administrativo deve ser excepcional.

## Controles
- conta administrativa separada;
- MFA resistente a phishing quando possível;
- elevação sob demanda;
- logging;
- estações administrativas protegidas;
- proibição de uso cotidiano com privilégio;
- revisão frequente de grupos críticos;
- credenciais protegidas e rotacionadas.

O objetivo é reduzir exposição e limitar impacto caso uma identidade seja comprometida.
