# Detection Rule Quality

Uma regra útil precisa ter objetivo claro, fonte de dados conhecida e resposta operacional definida.

## Checklist
- hipótese de ameaça explícita;
- campos necessários documentados;
- filtros de exclusão justificáveis;
- severidade coerente;
- exemplo benigno e suspeito;
- procedimento de triagem;
- possibilidade de teste;
- revisão periódica de ruído.

Regras que ninguém sabe investigar viram apenas volume de alerta.
