# IOC Handling

Indicadores devem ser tratados com contexto.

## Tipos
- hash;
- domínio;
- URL;
- IP;
- caminho;
- nome de arquivo;
- chave de registro;
- certificado;
- identificador de conta.

IOC isolado pode envelhecer rapidamente. Combine indicador com comportamento, origem, primeira/última ocorrência e confiança antes de bloquear.
