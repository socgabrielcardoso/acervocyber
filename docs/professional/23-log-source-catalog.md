# Log Source Catalog

Fontes comuns para investigação:

| Fonte | Uso |
|---|---|
| Identity | logons, MFA, sessões e privilégios |
| Endpoint | processos, arquivos, persistência e rede |
| Firewall | conexões, bloqueios e volume |
| DNS | resolução e infraestrutura externa |
| Proxy/Web | navegação e downloads |
| Email | phishing e entrega |
| Cloud | alterações administrativas e recursos |
| Application | autenticação e eventos de negócio |

Conhecer cobertura e retenção é parte da defesa.
