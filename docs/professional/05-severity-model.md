# Severity Model

Modelo simples para priorização:

| Severidade | Critério |
|---|---|
| Informational | Telemetria útil sem risco imediato |
| Low | Desvio pequeno ou controle preventivo |
| Medium | Comportamento suspeito com impacto limitado |
| High | Forte evidência de comprometimento ou impacto relevante |
| Critical | Comprometimento ativo, impacto amplo ou risco material imediato |

A severidade deve considerar impacto, confiança da detecção, criticidade do ativo, alcance e possibilidade de abuso continuado.
