# KQL Query Principles

Consultas de investigação devem ser legíveis, reproduzíveis e limitadas ao período necessário.

## Estrutura
- selecionar a tabela correta;
- restringir tempo cedo;
- filtrar entidades relevantes;
- projetar apenas campos úteis;
- ordenar para facilitar análise;
- resumir somente depois de preservar detalhe.

## Regra
Uma consulta boa não é a mais longa: é a que testa uma hipótese específica e permite explicar o resultado.
