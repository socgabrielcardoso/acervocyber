# Incident Analysis Framework

Fluxo recomendado para análise defensiva:

1. **Triage** — identificar ativo, usuário, origem, horário e severidade.
2. **Contexto** — validar função do ativo, comportamento esperado e janela temporal.
3. **Evidência** — correlacionar logs de endpoint, identidade, rede e aplicação.
4. **Hipóteses** — listar explicações possíveis e testar cada uma.
5. **Escopo** — procurar sinais relacionados em outros ativos ou identidades.
6. **Contenção** — aplicar somente controles proporcionais ao risco observado.
7. **Erradicação** — remover persistência, artefatos e causas raiz.
8. **Recuperação** — validar operação normal.
9. **Lições aprendidas** — registrar melhoria de detecção ou processo.
