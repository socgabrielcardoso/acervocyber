# Threat Hunting Cycle

1. Formular hipótese.
2. Identificar dados necessários.
3. Criar consulta reproduzível.
4. Revisar resultados e pivôs.
5. Separar normal de anômalo.
6. Validar entidades relacionadas.
7. Registrar achados.
8. Converter padrões úteis em detecções.

Hunting não é procurar qualquer coisa estranha: é testar uma hipótese com dados e critério.
