# Content Standard

Cada material técnico deve preferencialmente conter:

- contexto e objetivo;
- pré-requisitos;
- hipótese ou risco analisado;
- evidências observáveis;
- procedimento de validação;
- decisão defensiva;
- remediação;
- limitações;
- referências técnicas quando aplicável.

## Linguagem
Priorizar clareza operacional. Evitar afirmar certeza absoluta quando os dados só sustentam hipótese.

## Segurança
Exemplos devem usar dados sintéticos, endereços reservados e ambientes de laboratório.
