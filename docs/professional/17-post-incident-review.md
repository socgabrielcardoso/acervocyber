# Post-Incident Review

Após o incidente, responder:

- Qual foi o vetor inicial?
- Qual controle detectou?
- Qual controle falhou ou estava ausente?
- Quanto tempo levou para detectar e conter?
- Que evidência faltou?
- Houve impacto?
- A regra pode ser melhorada?
- Existe ação preventiva mensurável?

A revisão deve produzir melhorias concretas, não apenas narrativa.
