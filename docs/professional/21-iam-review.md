# IAM Review

Revisão periódica de identidade deve verificar:

- contas inativas;
- contas sem MFA;
- privilégios elevados;
- grupos críticos;
- métodos de autenticação;
- convidados;
- aplicativos com consentimento;
- contas de serviço;
- credenciais antigas;
- sessões e tokens anômalos.

A revisão deve resultar em remoção de acessos desnecessários e evidência de aprovação para exceções.
