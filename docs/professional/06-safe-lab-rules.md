# Safe Lab Rules

- Usar somente máquinas, contas e redes próprias ou explicitamente autorizadas.
- Preferir dados sintéticos e ambientes isolados.
- Nunca publicar tokens, senhas, cookies, chaves privadas ou dados pessoais reais.
- Não reutilizar indicadores sensíveis de ambientes corporativos.
- Documentar qualquer dependência externa.
- Manter experimentos destrutivos fora do host principal.
- Antes de compartilhar resultados, revisar logs, screenshots e arquivos para remover informação sensível.

O objetivo do laboratório é aprender defesa com rastreabilidade e responsabilidade.
