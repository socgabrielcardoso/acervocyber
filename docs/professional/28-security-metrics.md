# Security Metrics

Métricas úteis devem orientar decisão, não só decorar dashboard.

## Exemplos
- MTTD e MTTR;
- alertas por severidade e fonte;
- taxa de falso positivo;
- incidentes por vetor;
- vulnerabilidades críticas vencidas;
- cobertura de MFA;
- endpoints em compliance;
- ativos sem telemetria;
- backlog de remediação.

Toda métrica deve ter dono, periodicidade e ação associada quando sair do limite esperado.
